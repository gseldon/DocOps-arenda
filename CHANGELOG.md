# CHANGELOG

Все значимые изменения в проекте "Система генерации договоров аренды" документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [Unreleased]

### Добавлено
- `docx_builder.py`: общий код сборки DOCX для обоих скриптов
- `contract_utils.py`: проверка данных, числа прописью со склонением, форматирование дат и сумм
- Параметры командной строки `--data`, `--check`, `--output`
- Проверка входных данных (поля, форматы, заглушки шаблона) с понятным списком ошибок
- Автотесты `tests/test_generation.py`
- `example/contract_data.example.json` с вымышленными данными
- Необязательные параметры `prolongation_months`, `prolongation_notice_days`, `indexation_notice_days`; флаг `animals_allowed_by_default` теперь действует

### Изменено
- Шаблон данных: убраны `monthly_rent_text` и `security_deposit_text` (пропись считается автоматически)
- DOCX пишется напрямую в zip без временных папок, добавлены `styles.xml` и свойства документа
- `requirements.txt`: убраны неиспользуемые зависимости (python-docx, pillow, requests)
- README: исправлены пути, имена выходных файлов, версия, описание `meters`, раздел параметров и ограничений

### Исправлено
- Даты, залог, неустойка, срок пролонгации, сроки уведомлений и год в договоре берутся из JSON, а не из кода
- Число и пропись в скобках согласованы и склоняются («1 (одно) лицо», «5 (пяти) рабочих дней»)
- Экранирование `&`, `<`, `>` в значениях: файл больше не повреждается
- Форматирование суммы не портит запятые в тексте; используется неразрывный пробел
- `footerReference` первым в `sectPr`; сетка таблиц соответствует числу колонок; приложения начинаются с новой страницы
- В сводке название банка, статус собственности и состав счётчиков берутся из данных
- Убрано упоминание Markdown-сводки, которой скрипт не создаёт

## [1.0.0] - 2025-11-17

### Добавлено
- Автоматическая генерация договоров аренды в формате DOCX
- Автоматическая генерация сводок по договорам в формате DOCX
- Система управления персональными данными через JSON файл
- Шаблон данных для новых пользователей (`contract_data.template.json`)
- Автоматическая нумерация версий документов с временными метками
- Организация документов в структуре папок: `doc/` для договоров, `doc/summary/` для сводок

### Структура проекта
- `create_contract.py` - скрипт генерации договора аренды
- `create_summary.py` - скрипт генерации сводки
- `contract_data.json` - файл с персональными данными (защищен .gitignore)
- `contract_data.template.json` - шаблон для заполнения
- `requirements.txt` - файл зависимостей проекта
- `README.md` - полная документация с примерами
- `.gitignore` - правила исключения для Git
- `doc/` - папка для сгенерированных договоров
- `doc/summary/` - папка для сгенерированных сводок
- `example/` - папка с референсными документами

### Функциональность договора
- Информация о сторонах (Арендодатель/Арендатор)
- Данные о помещении (адрес, кадастровый номер, площадь)
- Финансовые условия (арендная плата, залог, штрафы)
- Банковские реквизиты для оплаты
- Автоматическая пролонгация договора (11 месяцев)
- Индексация арендной платы при пролонгации (не более уровня инфляции)
- Правила проживания (количество жильцов, животные)
- Условия передачи показаний счетчиков (15 числа до 23:00)
- Условия расторжения договора
- Опись имущества (Приложение 1)
- Показания счетчиков (Приложение 2)

### Технические особенности
- Использование только стандартных библиотек Python 3.6+
- Генерация DOCX файлов без внешних зависимостей
- Поддержка кириллицы и форматирования
- Автоматическая нумерация страниц
- Версионирование файлов с датой и временем

### Безопасность
- Защита персональных данных через `.gitignore`
- Разделение реальных данных и шаблонов
- Обезличенные примеры в документации

### Документация
- Полная инструкция по установке и использованию
- Описание структуры JSON файла с данными
- Примеры использования
- Рекомендации по безопасности
